writeup: |
  Both messages used the same pad. XORing the two ciphertexts cancels the key and leaves *plaintext 1 XOR plaintext 2*. Message 1 is a weather report you already have, so XORing it back out leaves message 2: `SHIPMENT ARRIVES TUESDAY. ANSWER: VENONA`.

  Venona was the real project that read Soviet messages for decades because some one-time pad pages were used twice. Weather reports were the codebreakers' favourite guessable text.
