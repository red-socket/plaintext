  Two symbols in groups of eight: binary in disguise. The only question is which square is 0.

  Every group starts with a light square, and every ASCII letter starts with a 0 bit, so light is 0 and dark is 1. Then `□■□■□□□■` is `01010001`, 81, which is Q. The tiles spell `QUARTZ`.
